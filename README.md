# 📖 Conck - 命令行通讯录管理系统 (CLI)

## 📝 简短介绍

Conck 是一个基于 Java 编写的轻量级、纯命令行通讯录管理系统。项目采用严格的职责分离架构，将数据模型、业务逻辑、持久化存储与用户交互（纯 I/O）完全解耦。

**核心特性：**
- **极简的 CLI 交互**：使用极简快捷键（`rv`, `ct`, `ud`, `dl`, `qt`）操作，并统一通过 `rt` 返回上一级。**指令严格区分大小写**。
- **终端表格化输出**：自带中英文宽度自适应的表格展示（通过 `ConsoleUI` 中的 `isWide` 判定），完美处理 CJK 字符与 Emoji 的终端对齐问题，并清理了控制字符。
- **JSON 数据持久化**：使用 Gson 进行数据的序列化与反序列化，彻底解决原有纯文本格式的特殊字符（如 `|`）冲突问题。
- **防断电/崩溃安全设计**：基于 NIO 实现了**原子写入**机制（先写 `.tmp` 再原子替换），保证写入数据时即使异常退出也不会损坏原有的通讯录文件。
- **一键原生打包**：支持 JDK 自带的 `jpackage` 工具，可打包成包含私有 JRE 的独立可执行文件（`app-image`），实现无 Java 环境下的双击即用。

**技术栈：** Java (JDK 16+) / Gson (2.10+) / 面向接口编程 / Stream API / NIO.2

---

## 🚀 如何使用

启动程序后，你将看到主菜单。输入以下快捷键（**严格区分大小写**，所有子页面通用 `rt` 返回）：

- `rv` (Retrieve) ：进入查询页（支持按名字 `nm` 排序、号码 `nb` 排序，或直接输入文本进行模糊搜索）。
- `ct` (Create)   ：进入添加页（依次输入姓名、号码）。
- `ud` (Update)   ：进入修改页（搜索 -> 选择目标 -> 指定字段 `nm` 或 `nb` -> 输入新值）。
- `dl` (Delete)   ：进入删除页（搜索 -> 选择目标 -> 输入 `yes` 确认删除）。
- `qt` (Quit)     ：保存数据并退出程序。
